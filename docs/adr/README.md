# 架构决策记录（ADR）

Helm 的架构决定在这里成文：一件一个文件，编号递增，不复用编号。格式取 Nygard / MADR 的精简形，包括背景、决策驱动、方案、决策、后果、跟进与参考。

- **状态**：提议 → 已接受 → 已取代（注明由哪一件取代）。已接受的 ADR 不改写正文；改主意就另立新件，并在旧件的状态行标注「被 ADR-xxxx 取代」。
- **证据**：每条决策都指向本仓代码、fixture 或一手材料。未核实的内容标为「待确认」或「待裁」，不写成事实。
- **公开仓**：本仓公开。私有材料只引用其语义与出处，不转录内容；不写入任何凭据、个人信息或案件线内容。
